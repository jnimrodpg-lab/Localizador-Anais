WMS Industrial V179 – ajustes aplicados

1. Calles / intersecciones
- Las calles laterales y superior/inferior ahora se proyectan y extienden para unirse de forma continua.
- Se reconstruye automáticamente la red de calles al crear o actualizar una calle.
- El estilo de esquina diagonal también se reaplica sobre la red existente.
- En el plano 2D se mejoró la lectura visual: orden correcto de vereda/calle/vereda, eje central punteado y etiquetas más legibles.

2. Editor de layout
- Al ocultar las secciones, el canvas principal recupera mejor la altura disponible.
- Se forza un refit del viewBox para que el layout aproveche el espacio liberado.

3. Diseñar espacio 3D
- Se mejoró el diorama con una base contenedora para que el conjunto no quede más grande que el piso.
- Las calles ahora se renderizan como superficies superiores sobre la base, evitando “cortinas” o extrusiones visuales erróneas.
- Se mejoraron materiales, luces y nitidez general del diorama.
